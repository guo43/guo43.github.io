#### 2. JsonUtlity

- 序列化

  序列化不支持字典

  私有化字段（**增加[serializefield]**)

  自定义类，需要增加[**serializable**]

  字段没有赋值会初始化默认值

  ```cs
  using System.Collections.Generic;
  using System.IO;
  using UnityEngine;
  
  public class Person
  {
      public string name;
      public int age;
      public bool sex;
      public float testF;
  
      public int[] ids;
      public List<int> ids2;
      public Dictionary<int, int> scores;
      public Person friend;
  }
  
  
  public class JsonTest : MonoBehaviour
  {
      void Start()
      {
          Person person = new Person();
          person.name = "张三";
          person.age = 20;
          person.sex = true;
          person.testF = 99.9f;
          person.ids = new int[] { 1, 2, 3, 4, 5 };
          person.ids2 = new List<int>() { 11, 22, 33, 44, 55 };
          person.scores = new Dictionary<int, int>();
          person.scores.Add(1, 100);
          person.scores.Add(2, 90);
          person.scores.Add(3, 80);
          person.friend = new Person();
          person.friend.name = "李四";
          person.friend.age = 18;
  
          string json = JsonUtility.ToJson(person);
          Debug.Log("Serialized JSON: " + json);
  
          File.WriteAllText(Application.persistentDataPath + "/person.json", json);
      }
  }
  ```

  

  ```json
  {
      "name":"三",
      "age":20,
      "sex":true,
      "testF":99.9000015258789,
      "ids":[1,2,3,4,5],
      "ids2":[11,22,33,44,55]
  }
  ```

  

- 反序列化

  ```csharp
  Person p = JsonUtility.FromJson<Person>(File.ReadAllText(Application.persistentDataPath + "/person.json"));
  ```

#### 3. LitJson

定义：第三方库，用于处理Json的序列化与反序列化

支持字典，键会转化为string

支持数据集合



#### 4. 对比

LitJson不需要加特性，支持字典，

JsonUtility存储没有赋值的字段时会初始化默认值，LitJsonNull存储更准确
