# Markdown 使用指南

Markdown 是一种轻量级标记语言，非常适合用来编写博客文章。

## 标题

Markdown 支持 6 级标题：

# 一级标题
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题

## 文本格式

- **粗体文本**
- *斜体文本*
- ~~删除线~~
- `行内代码`

## 代码块

支持多种编程语言的语法高亮：

```python
def hello():
    print("Hello, World!")
```

```javascript
const greet = (name) => {
    console.log(`Hello, ${name}!`);
};
```

## 表格

| 功能 | 支持 | 说明 |
|------|------|------|
| 标题 | ✅ | 支持 6 级标题 |
| 列表 | ✅ | 有序和无序列表 |
| 代码 | ✅ | 行内和代码块 |
| 表格 | ✅ | 标准表格格式 |

## 任务列表

- [x] 已完成的任务
- [ ] 未完成的任务
- [ ] 另一个任务

Markdown 语法简单易学，是编写技术博客的理想选择。
