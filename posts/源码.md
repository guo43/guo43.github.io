## 一、Queue

`Queue`通过双指针循环队列实现

- 默认长度为32
- 扩容2倍
- 队列满了，会扩容，调用SetCapacity函数，创建一个新数组，调用Array拷贝函数复制_array中的值。同时将新数组赋值给_array。
- 不是线程安全的

`ConcurrentQueue` 是线程安全的，是一个`Queue wrapper`

- 使用一个链表实现

  ```cs
  // 简化版内部结构
  private class Segment
  {
      internal readonly T[] _array;           // 存储元素的数组
      internal volatile Segment _next;        // 下一个段
      private volatile int _state;            // 段的状态标志
      private int _head;                      // 段内出队位置
      private int _tail;                      // 段内入队位置
      private int _freezeOffset;              // 冻结偏移量
  }
  
  private volatile Segment _head;    // 队列头段（用于出队）
  private volatile Segment _tail;    // 队列尾段（用于入队）
  ```

- 在操作数据的函数中加锁

- 默认也是两倍扩容



```csharp

        _array[_tail] = obj;
```

## 二、String

`string`是一个不可变的字符串，使用+号回产生新对象，并且占用内存。

`string`类型变量是在堆上分配内存的。

1. 两字符串比较
   - 首先比较引用，内部对string进行`装箱`成object，比较两个对象的引用地址是否相同
   - 然后...
2. 两个字符拼接
   - 会转换成Concat
   - 如果其中一个为Null，则返回另一个
   - 否则，计算两个字符总长度，分配内存
   - 然后将两个字符串拷贝到新分配的string中
