# 特效测试指南

## 为什么看不到特效？

### 1. 必须使用本地服务器 ⚠️

**重要**：不能直接双击打开 HTML 文件！必须使用本地服务器。

**正确方式**：
```bash
# 在项目根目录执行
python -m http.server 8000
# 然后访问 http://localhost:8000
```

**错误方式**：
- ❌ 直接双击 `index.html` 打开
- ❌ 使用 `file://` 协议访问

### 2. 检查浏览器控制台

按 `F12` 打开开发者工具，查看 Console 标签：

- ✅ 如果看到 `✅ 特效初始化完成`，说明特效已加载
- ❌ 如果看到错误信息，请检查文件路径是否正确

### 3. 测试各个特效

#### 页面淡入动画
- **效果**：页面加载时从下方淡入
- **测试**：刷新页面（F5），观察页面是否从下方淡入显示

#### 返回顶部按钮
- **效果**：滚动超过 300px 时，右下角显示蓝色圆形按钮
- **测试**：
  1. 向下滚动页面
  2. 观察右下角是否出现蓝色圆形按钮（↑）
  3. 点击按钮，页面应平滑滚动到顶部

#### 文章卡片悬停效果
- **效果**：鼠标悬停在文章卡片上时，卡片上移并显示阴影
- **测试**：
  1. 将鼠标移到文章卡片上
  2. 观察卡片是否上移、显示阴影、背景色变化

#### 导航链接下划线
- **效果**：鼠标悬停在导航链接上时，从左侧滑出下划线
- **测试**：
  1. 将鼠标移到"首页"或"关于"链接上
  2. 观察是否出现蓝色下划线动画

#### 滚动淡入动画
- **效果**：文章卡片滚动到视口时淡入显示
- **测试**：
  1. 刷新页面
  2. 慢慢向下滚动
  3. 观察文章卡片是否在进入视口时淡入显示

#### 代码块复制按钮
- **效果**：鼠标悬停在代码块上时，右上角显示"复制"按钮
- **测试**：
  1. 打开一篇文章（包含代码块）
  2. 将鼠标移到代码块上
  3. 观察右上角是否出现"复制"按钮
  4. 点击按钮，代码应被复制到剪贴板

### 4. 常见问题排查

#### 问题：页面没有淡入动画
**可能原因**：
- CSS 文件未正确加载
- 浏览器缓存问题

**解决方法**：
1. 检查浏览器控制台是否有 CSS 加载错误
2. 按 `Ctrl + F5` 强制刷新页面
3. 检查 `css/effects.css` 文件是否存在

#### 问题：返回顶部按钮不显示
**可能原因**：
- 页面高度不够（需要滚动超过 300px）
- JavaScript 未正确执行

**解决方法**：
1. 确保页面内容足够长，可以滚动
2. 检查浏览器控制台是否有 JavaScript 错误
3. 检查 `js/effects.js` 文件是否存在

#### 问题：文章卡片没有悬停效果
**可能原因**：
- CSS 样式被覆盖
- 文章列表还未加载完成

**解决方法**：
1. 等待文章列表加载完成
2. 检查浏览器控制台是否有错误
3. 尝试刷新页面

#### 问题：所有特效都不工作
**可能原因**：
- 直接打开了 HTML 文件（file:// 协议）
- JavaScript 文件路径错误
- 浏览器不支持某些特性

**解决方法**：
1. ✅ **必须使用本地服务器**（最重要！）
2. 检查所有文件路径是否正确
3. 检查浏览器控制台的错误信息
4. 尝试使用现代浏览器（Chrome、Firefox、Edge）

### 6. 调试技巧

在浏览器控制台执行以下代码，检查特效是否加载：

```javascript
// 检查特效函数是否存在
console.log('initScrollAnimations:', typeof initScrollAnimations);
console.log('initBackToTop:', typeof initBackToTop);
console.log('initCodeCopyButtons:', typeof initCodeCopyButtons);

// 检查返回顶部按钮是否存在
console.log('返回顶部按钮:', document.querySelector('.back-to-top'));

// 检查文章卡片
console.log('文章卡片数量:', document.querySelectorAll('.post-item').length);
```

### 7. 如果还是不行

1. **检查文件结构**：
   ```
   Blog/
   ├── css/
   │   ├── style.css
   │   └── effects.css  ← 确保这个文件存在
   ├── js/
   │   └── effects.js   ← 确保这个文件存在
   └── index.html
   ```

2. **检查 HTML 文件中的引用**：
   ```html
   <link rel="stylesheet" href="css/effects.css">
   <script src="js/effects.js"></script>
   ```

3. **清除浏览器缓存**：按 `Ctrl + Shift + Delete` 清除缓存

4. **尝试其他浏览器**：Chrome、Firefox、Edge
